# projeto2
Projeto 2 de Programação Eficaz

## Configuração do banco de dados

1. Copie o arquivo `.env.example` para `.env`.
2. Preencha no `.env` o usuário e a senha do seu MySQL.
3. Inicie a aplicação normalmente.

A aplicação cria automaticamente o banco configurado em `DB_NAME` e a tabela
`imoveis`, caso ainda não existam. O servidor MySQL precisa estar instalado e
em execução, e o usuário informado precisa ter permissão para criar bancos.
